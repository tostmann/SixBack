Share diagnostic snapshots: … Off by default. When on, the ESP uploads pre-migration snapshots to sixback.io for the maintainer to debug support requests. Sent data: speaker identity (MAC, model, firmware) + preset + source state + speaker configuration.
Web UI password: … Off by default — anyone on your LAN can open this UI. When on, your browser asks for a username + password (digest auth: the password is never sent in cleartext, and only a hash is stored on the device). Note: page content and the speaker's own controls stay reachable on the LAN — this is deterrence, not network isolation. Forgot the password? Send auth-reset over the USB serial console.
Keep error messages on screen: … On by default: a red error message stays until you click it away (or click the ×), so a warning like presets could not be written to flash can't vanish before you have read it. Switch off and errors disappear after 4 seconds again, like the green ones. This is a setting of this browser, not of the stick — it is not stored on the device.
Hostname (.local): … Default sixback — change this when you run two SixBack sticks in one network (both would otherwise announce sixback.local). Allowed: a-z, 0-9, dash; max 24 chars. Leave empty + Save to reset. Takes effect after a reboot.
